## Featured project

### [moodle-aws-iac](https://github.com/iuricardosopro-ui/moodle-aws-iac)
Production-style, multi-environment Infrastructure as Code for a
containerized Moodle platform on AWS — built to demonstrate the full
lifecycle from IaC to CI/CD to cost governance.

- 10 reusable Terraform modules shared across dev/staging/prod via workspaces
- Two GitHub Actions pipelines with OIDC auth, automated vulnerability
  scanning (Trivy) and static analysis (Checkov, tflint) gating every deploy
- WAF, CloudWatch monitoring/alerting, and a sourced, methodology-documented
  cost analysis
